# StudyHub

A premium product showcase for StudyHub, an AI-powered learning platform by Sarah Pardeshi.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production build

```bash
npm run build
npm start
```

The showcase video is served from `public/videos/studyhub-demo.mp4`.

## Deploy

Import this repository into Vercel. The default Next.js build settings are configured in the project.
